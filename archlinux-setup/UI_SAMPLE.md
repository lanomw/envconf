# 配置交互界面样例

下面是主菜单与**批量多选子菜单**的文本示意（实际在终端中以 curses 绘制，带颜色/反白）。

## 主菜单（示例：未勾选任何开发工具，WSL 环境）

```
========================================
Arch Linux 初始化配置
========================================
—— 系统基础
  [ ] Locale
  [ ] 时区
  [ ] 基础软件包
  [-] CPU 微码 (WSL 不适用，微码由 Windows 宿主管理)
—— 系统服务
  [-] NTP 时间同步 (WSL 默认同步 Windows 宿主时间)
  [ ] SSH 服务端
  [ ] 定时任务
  [ ] 防火墙 (ufw)
—— 终端美化
  [ ] Zsh 美化
  [ ] 字体 (Nerd/中文)
  [ ] 终端提示符 (starship)
—— 开发工具
  [ ] NeoVim (LazyVim)
> 编程语言 (未选) ▶                 <-- 当前高亮
  C/C++ 工具 (未选) ▶
  Git 工具 (未选) ▶
—— AUR
  [ ] AUR 助手 (yay)
  [ ] AUR 助手 (paru)
—— CLI 增强
  [ ] 终端工具 (tmux/btop/eza/bat/zoxide/fd/ripgrep)
  [ ] 终端编辑器 (helix/micro)
  [ ] 文件管理 (yazi)
  ...
—— 容器
  [ ] Docker
—— WSL
  [ ] WSL systemd

  [ 执行 ]
  [ 退出 ]

↑↓移动 · 空格勾选/进入/执行 · q退出   |   空格: 批量选择
底部详情栏：Shell 与终端提示符 — Zsh 是 Shell，starship 是提示符；安装 starship 后 ~/.zshrc 会自动初始化
```

操作说明：

- `↑↓` 在可选行间移动，标题（`——`）和分隔线会自动跳过。
- `空格` / `回车`：普通项直接勾选/取消；带 `▶` 的父级行进入子菜单。
- 选中 `编程语言` 后按空格进入下面的批量多选子菜单。

## 批量多选子菜单（示例：勾选 Python、Go、Rust）

```
==== 编程语言 （方向键 + 空格切换，回车/esc/q 返回） ====
> [*] Python
    [*] Rust (rustup)
    [*] Go
    [ ] Java (OpenJDK)
    [ ] Node.js 运行时 (bun/deno)
    [ ] Lua
    [ ] PHP
    [ ] Ruby

↑↓移动 · 空格切换 · 回车/esc/q 返回   |   空格: 切换选中
底部详情栏：Python 解释器与标准库  ·  安装: python
```

返回主菜单后父级行会更新：

```
—— 开发工具
  [ ] NeoVim (LazyVim)
> 编程语言 (已选 3/8: Python, Rust, Go) ▶
  C/C++ 工具 (未选) ▶
  Git 工具 (未选) ▶
```

## 父级规则

- **编程语言**：包含 8 个独立语言，可多选。
- **C/C++ 工具**：仅 2 项（clang / valgrind），独立可选，无强制捆绑。
- **Git 工具**：3 项 Git 增强（diff 高亮 / TUI / 扩展），可按需多选，不互斥。
